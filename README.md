# 安居协议 · 末日安全屋求生

浏览器可玩的第一视角安全屋生存原型。玩家从简陋平房开始，检视并加固门窗、守住夜晚、积攒资源，逐步迁入小木屋、二层小洋房和高楼安全屋。游戏会在当前浏览器中自动保存进度。

这是纯静态 HTML、CSS 和 JavaScript 网站。GitHub Pages 从仓库 `main` 分支的根目录发布；`.nojekyll` 让游戏文件直接作为静态资源提供。

场景图片由 AI 图像工具辅助制作，玩法、故事、视觉方向与交互由项目作者设计，代码在 AI 协作下开发。游戏没有运行时 AI 接口，也不是实时 3D 游戏。音频素材由项目作者提供；本仓库未授予第三方复用这些素材的许可。
